# Demo 09 - "Both hands"

Week 9 clip. Target length 45-55 s, 16:9, captions burned in, sound on (Mochi speaks once). Shows that both hands are now full pointers: the left hand draws with the create ring while the right hand navigates, and the new stop gesture.

## Setup (before recording)

1. `pnpm dev`; open http://127.0.0.1:5173 in Edge (dark theme), sample project open. Claude Code signed in for the last shot.
2. Front light on both hands; Windows Studio Effects off. Sit far enough back that both hands fit in the camera image with room to move.
3. Start the camera and check the Detection card: both hands found close to 100%.
4. In the Gestures card, check the long pinch reads **Open the create ring** (left) and **Open the tools ring** (right).
5. Off camera, draw and undo one wall so the timing is in your hands.
6. Recorder at 1080p, 30 fps, capturing the browser window and system audio.
