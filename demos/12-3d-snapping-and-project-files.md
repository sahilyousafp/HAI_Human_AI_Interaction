# Demo 12 - "From a blank project to a Rhino file"

Week 12 clip. Target length 45-60 s, 16:9, captions burned in. A new empty project, a dropped-in Rhino model, a wall snapped to a rooftop corner three floors up, a measurement corner to corner, and the project saved as a Rhino file and opened in Rhino. Show my hands is on.

## Setup (before recording)

1. `pnpm dev`; open http://127.0.0.1:5173 in Edge, light theme.
2. Front light on both hands; Windows Studio Effects off. Start the camera and check both hands are found close to 100%.
3. Settings > Drawing aids: Endpoint on (and Midpoint if you like).
4. A Rhino file of a few buildings ready next to the browser, saved without Save small. Rhino 8 open on the desktop for the last shot.

## Shot list

| # | Time | Do | Voice-over / caption |
|---|---|---|---|
| 1 | 0-8 s | Press New project, type a folder, Create: the sample building goes and a clean ground appears. | "A clean space to start in." |
| 2 | 8-16 s | Drop the .3dm on the model; read the report. | "Drop in a Rhino model." |
| 3 | 16-30 s | Left hand: create ring, Wall. Point at the top corner of a tall building: the Endpoint ring shows up there. Drag across the roof: the wall is drawn level, on the roof. | "Snaps now work at any height, not just on the ground." |
| 4 | 30-42 s | Measure: tap a bottom corner and a roof corner; read the notice with its across and up parts. | "Measure snaps too, with the vertical part." |
| 5 | 42-50 s | Press Save as 3dm; the file downloads. | "And save it as a Rhino file." |
| 6 | 50-58 s | Open the file in Rhino: the walls and slabs are real extrusions on their own layers. | "Real Rhino geometry, on layers, with names." |
