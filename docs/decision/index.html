Decision record / gesture + agent interaction for AEC

Build the hands, not the modeler.

Own the interaction layer: webcam hand and face tracking, a HUD, and an agent loop that runs in the browser. Let Rhino do the precise geometry through MCP. Blender comes second. Everything below shows how that answer was reached, and lets you change the weights and see if it still holds.

Your question Rhino or Blender, or my own UI?

Both. Build your own UI, but not your own modeler, then plug it into Rhino first. A Rhino-only plugin limits you to people who own a $995 license, and McNeel already ships its own AI panel.

Why own the UI The gap is the interaction layer

No maintained project combines webcam gestures with an LLM agent for CAD or BIM. MediaPipe also runs fastest in the browser: GPU on Windows, no hops between processes, and video stays on the laptop.

Why not a new modeler Rhino already solved geometry

Rebuilding NURBS, booleans and IFC would eat months of a 6-hour week. McNeel's MIT-licensed RhinoAI MCP and rhinomcp already let an agent drive Rhino.

Two speeds of control

  • Fast path, under 50 ms: gestures and head pose drive orbit, zoom, pan, select and confirm. Fixed rules, no LLM in the loop.
  • Slow path, a few seconds: voice plus pointing becomes an intent ("make this wall 300 thick"). The agent calls MCP tools.
  • Proposals as ghosts: the agent's change shows as a preview. Pinch, thumbs up or a nod accepts it. One undo reverts the whole agent turn.
  • Privacy: only landmarks and intents leave the tracking worker. Video never leaves the device.

A5 / risks and rules

Using your subscription plan safely

From Anthropic's legal and compliance page and the consumer terms, read on 2026-10-19. This is not legal advice. The rules have changed several times in 2026, so keep the provider layer swappable.

Lowest risk
  • You run your own Claude Code, signed in yourself, on your own machine. This is how this project works.
  • App spawns the unmodified claude binary for one user; nothing is resold or hosted
  • User's own API key, or Max monthly API credits ($100 or $200)
  • Codex with a ChatGPT plan, or "Sign in with ChatGPT" (preview)
  • Local models through Ollama
Grey zone
  • Turning the app into a hosted service where others' requests run through one person's plan
  • Unusually heavy automated use may not count as "ordinary individual usage"; watch your plan limits
  • Each user should install and sign in to their own Claude Code; the README says so
Not allowed
  • A "Sign in with Claude" button in your app
  • Reading, storing or proxying Claude.ai tokens or credentials
  • Spoofing Claude Code headers
  • "Claude Code" in the product name ("Powered by Claude" is fine)

Project risks

Open questions to settle early

  1. Does an open-source app that spawns the user's own logged-in claude -p count as routing requests on behalf of users? Get a written answer from Anthropic.
  2. Does claude -p with an API key draw from the Max monthly credits? The docs say the credits do not cover "Claude Code".
  3. What frame rate do hands and face together actually reach on your laptop? Benchmark in week 2.
  4. What are HaGRIDv2's extra license terms? Read them before publishing trained weights.
  5. Does a click-through Electron overlay composite cleanly over Rhino 9's Direct3D viewport?
