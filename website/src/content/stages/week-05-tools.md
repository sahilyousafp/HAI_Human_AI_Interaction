The ring is a marking menu, an idea from 1990s HCI research. It suits hand tracking well: you flick towards a tool rather than steering a pointer onto it.

Editing tools need safety rails before anyone trusts them, so every tool that changes the model has a way back: a flick to undo, a nod to confirm, a fist to escape.

None of this needs an AI agent yet. Every change runs as an ordinary scene transaction, the same path the agent's edits will take next.
